SBSMS OTP PASSWORD RESET

Implemented:
- Forgot Password button opens gui.ForgotPassword.
- Final reset checks Account ID, a six-digit OTP, matching passwords, and password policy.
- OTPs expire after five minutes and can only be used once.
- OTP hashes and passwords are stored as PBKDF2-HMAC-SHA256 hashes.
- The password update and OTP consumption run in one database transaction.
- Existing plaintext passwords remain compatible at login and are upgraded to PBKDF2 after successful login.

Important SMS limitation:
No SMS gateway/provider is configured in this project. PasswordResetService.createOtp(accountId)
creates and stores a hashed OTP and returns the raw code to the calling service so a configured SMS
provider can deliver it. Do not display or log the returned code in production. Until an SMS provider
is integrated and the first-step form calls createOtp only after checking the registered account/contact,
users cannot receive real OTP messages.

Database:
DatabaseConnection automatically creates password_reset_otps when the application initializes.
A standalone SQL script is also provided at database/password_reset_otp.sql.

Password policy:
At least 8 characters, including a letter, number, and symbol.

Build note:
The reset-related classes compile independently. A full project build still depends on the NetBeans
AbsoluteLayout library (org.netbeans.lib.awtextra), which was missing in the supplied ZIP/environment.
