Setup still required on the target computer:
1. Start MySQL in XAMPP.
2. Copy mysql-connector-j-9.4.0.jar into the project's lib folder (the third-party JAR is not bundled in this ZIP).
3. Ensure NetBeans has its AbsoluteLayout library available.
4. Import database/sbsms_setup.sql in phpMyAdmin, or let the app initialize the schema on its first database connection.
5. Open the project in NetBeans and Clean and Build.
